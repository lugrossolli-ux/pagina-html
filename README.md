# Sol de Alegría Eventos

Proyecto frontend para una empresa de eventos infantiles. La página permite mostrar servicios, eventos, perfiles de DJ, información del negocio y formularios de demostración.

El trabajo corresponde a la asignatura Full Stack 2 y fue realizado por:

- Franco Sepúlveda
- Luis Andrés Grossolli

## Sobre el proyecto

Sol de Alegría organiza celebraciones infantiles y ofrece servicios como DJ, música, sonido, iluminación, animación y catering. El sistema se adaptó a este contexto para mostrar una propuesta de navegación para clientes, administradores y personal de apoyo.

Actualmente el proyecto funciona como un prototipo frontend. Varias vistas utilizan datos de ejemplo y la navegación por roles es demostrativa.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git y GitHub

No se utilizan frameworks ni un proceso de compilación. Para revisar el proyecto se puede abrir `login.html` en el navegador y seleccionar el área que se quiere visualizar.

## Vistas principales

### Área pública y de usuario

- Página de inicio
- Información de la empresa
- Blogs
- Contacto
- Solicitud y detalle de eventos
- Perfiles de DJ
- Imágenes y controles de música
- Registro y acceso de demostración

### Área de administración

- Inicio del administrador
- Clientes
- Eventos
- Cotizaciones
- Personal
- Imágenes para eventos

Estas vistas muestran información estática o de ejemplo para representar el funcionamiento de la administración.

### Área de staff

- Eventos asignados
- Agenda
- Inventario

Esta sección complementa el caso de eventos y representa funciones que podrían ampliarse en una siguiente etapa.

## Backend relacionado

El frontend se desarrolló como continuación visual del backend de Sol de Alegría. El backend oficial se encuentra en otro repositorio y todavía no está conectado directamente a estas páginas:

[Repositorio backend de Sol de Alegría](https://github.com/Sepu5/soldealegria-sepulveda-pedraza-lisboa-003D)

La conexión con la API, la autenticación real y el uso de datos dinámicos quedan como mejoras posteriores.

## Plantilla utilizada

Para comenzar el frontend utilizamos como base la plantilla **Brynvel**, un dashboard HTML publicado por [html.design](https://html.design/). Después adaptamos su estructura, estilos y navegación al proyecto Sol de Alegría Eventos.

La plantilla sirvió como punto de partida visual, pero las páginas, textos, colores, datos de ejemplo y vistas fueron modificados para representar nuestro caso de eventos.
